# THE WEEPING WALLS
**Sealed Universe — Game One** · Act 1 Vertical Slice

A first-person gothic investigative horror game that runs entirely in the
browser. No engine download, no asset files — every texture, every sound,
every wall is generated by code at load time.

> *The house is the antagonist. Not a ghost. Not a monster. The house itself.*

## Play it

```bash
cd game
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a desktop browser (Chrome/Edge/Firefox).
Headphones strongly recommended.

| Input | Action |
|---|---|
| Mouse | Look |
| W A S D | Move |
| Shift | Move faster |
| E | Interact |
| J | Journal (notes · audio log · floor plan) |
| Esc | Close the recorder review deck |

## What's in the slice (Act 1 — Arrival)

- Arrival on the gravel drive at night — thirteen windows, count them
- Three iron keys; the front door; free exploration of the ground floor,
  staircase (mind the 7th step) and first floor
- The west wing door: locked, hinged on the wrong side
- **The kitchen wall** — press your palm against it
- Place four voice recorders, work past midnight at the kitchen table
- Review the overnight tapes: **02:47:16**
- Auto-writing journal with Mara's notes, audio log, and a floor plan that
  sketches itself room by room

## How it's built

Everything is authored in code (the "pure Fable 5" pipeline — no Blender,
no image generation, no sampled audio):

```
game/
  index.html              shell, HUD, journal, review deck, title & end cards
  lib/three.module.js     three.js r160 (vendored)
  src/
    engine/renderer.js    PSX pipeline: 240p render target, ordered dither,
                          posterise, grain, vertex snapping
    engine/controls.js    first-person controller, AABB collision, stairs
    world/textures.js     all surfaces painted procedurally on canvases
                          (implements the bible's Section 10 prompts in code)
    world/builder.js      walls-with-holes, floors, doors, colliders
    world/manor.js        Ashford Manor — every Act 1 room from Section 4
    audio/audio.js        synthesised: wind, room tone, footsteps, the
                          breathing wall, Eleanor's four-note theme, and the
                          2:47 AM "voice-shaped silence" (formant-filtered
                          noise — speech with the consonants stripped)
    game/                 state, HUD, journal, recorder deck, Act 1 script
```

Design source: [`docs/GAME_BIBLE.md`](docs/GAME_BIBLE.md) (full bible, v1.1).

## Testing

Headless playthrough tests (puppeteer) drive the whole act — enter, wall,
recorders, sleep, tape review, the voice — and screenshot each beat. The
game exposes `window.__game` (state/controls/script) for test automation.
